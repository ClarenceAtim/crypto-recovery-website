# Crypto Recovery Website

ChainGuard Recovery — crypto scam and wallet recovery website (placeholder brand).

Modelled on the structure of cryptorecovery.cloud, with original copy and real photos.
Hosted on GitHub Pages from this repo.

## Layout

- `index.html` — the whole site (single page: hero, case types, explainers, trace, method, FAQ, case form)
- `css/style.css` — all styling, including the dark theme
- `js/app.js` — trace tool, case form, seed-phrase safety filter, dark-mode toggle
- `assets/images/` — the 4 photos

## Features

- Free case review
- Free transaction trace (Bitcoin / Ethereum / Tron)
- Scam tracing and written reports for exchanges, police and lawyers
- Wallet access recovery for lost passwords and partial phrases
- Pricing: free review, wallet recovery success-fee only, tracing quoted after review
- Dark mode: a Dark / Light button in the top menu. It remembers the visitor's choice.
- The case form never asks for a recovery phrase or private key
